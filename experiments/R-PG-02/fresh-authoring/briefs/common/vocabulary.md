# Quantity names and their kinds

The names a design's quantities use where one fits. Spell a name exactly as it is here. A quantity for which no name fits may take a new name in lower snake_case. The unit column is each kind's SI unit; any unit of the same dimension may be written (see the format). Only the names marked **design choice** may take a `design:` source.
